# 终末地 · 产线倒计时

> Arknights: Endfield — Production Line Cap Countdown

一个用于《明日方舟：终末地》的产线倒计时工具。填写生产速度、消耗速度与当前存量，自动计算产物达到仓库上限的剩余时间，或者产物耗尽时间；可接入 **Server酱³**，在即将爆仓/耗尽时推送通知到手机上。

**[在线使用 →](https://darkyyx.github.io/endfield-timer/)**

---

## 功能特性

- **双地区上限支持** — 四号谷地 80,000 / 武陵 90,000，自动匹配对应容量
- **实时倒计时** — 根据净生产速度（生产 − 消耗）动态计算剩余时间，每秒刷新
- **状态一览** — 右上角实时显示「正常 / 预警」两类产线数量，预警不为 0 时变黄，出现已爆仓/已耗尽则转红
- **手机推送通知**（可选）— 经自建 Cloudflare Worker 调用 Server酱³，页面关着也能收到预警
- **显示设置** — 六种主题色可换（默认警戒黄），可自选中文与英文字体（含字体优先级），配置只保存在本机
- **数据持久化** — 所有数据自动保存至浏览器 `localStorage`，关闭页面后重新打开自动恢复
- **终末地视觉风格** — 暗色工业界面、扫描线、网格背景、高饱和高亮色，还原游戏 UI 氛围
- **零依赖** — 纯 HTML + CSS + JavaScript，无需构建工具，几个文件即可部署

---

## 使用说明

1. 点「**＋ 添加产物**」新增一条产线，填入生产/分、消耗/分与当前存量。
2. 确认无误后点该行的 **✓** 退出编辑态，倒计时开始计时。
3. 表格里会显示剩余容量与倒计时；右上角汇总有多少条处于预警状态。
4. 数据自动保存在本机浏览器，换设备不会同步（除非开启通知，见下）。

## 通知部署（可选）

通知链路：`网页端 → Cloudflare Worker → Server酱³ → 手机`。

### 第 1 步：准备 Server酱³

在 [Server酱³](https://sc3.ft07.com/) 注册，拿到 **SendKey**（形如 `sctp<UID><随机串>`）。

### 第 2 步：在 Cloudflare 建 KV 与 Worker

1. Cloudflare Dashboard → **Workers & Pages** → **KV** → 新建一个命名空间（例：`endfield-state`）。
2. → **Workers** → 新建 Worker，把本项目 `worker.js` 的全部内容粘贴进去并部署。
3. 在该 Worker 的 **Settings** 里绑定 KV：
   - **变量名必须是 `STATE`**（代码里按这个名字取），值选刚建的命名空间。
4. 配置变量（Settings → Variables and Secrets）：

   | 名称           | 类型               | 说明                                                                     |
   | -------------- | ------------------ | ------------------------------------------------------------------------ |
   | `SC_SENDKEY`   | Secret             | Server酱³ 的 SendKey                                                     |
   | `SYNC_TOKEN`   | Secret             | 自己随便生成一串随机字符串，防止别人访问你的数据                         |
   | `CLAIM_TOKEN`  | Secret（**可选**） | 强制夺回通知源用的口令（旧页面已打不开时用），不配则接管无需令牌         |
   | `WARN_SECONDS` | 可选               | 兜底预警窗口秒数，默认 `1800`（30 分钟）。**页面设置面板里的值会覆盖它** |
   | `TIME_ZONE`    | 可选               | 展示用时区的兜底值（小时偏移，如 `8`）。**页面设置面板里的值会覆盖它**   |

5. 添加定时触发器（Settings → Triggers → Cron）：**`*/5 * * * *`**（每 5 分钟）。

### 第 3 步：在页面上开启

1. 打开页面，展开底部的「**通知设置 · NOTIFICATION**」。
2. 填入 **Worker 地址**（形如 `https://xxx.yyy.workers.dev`）与**同步令牌**（即 `SYNC_TOKEN`）。
3. 设置「**预警时间**」（进入这个窗口就提醒一次）与「**时区**」（通知里预计时间所用的时区，默认 UTC+8）。
4. 勾选「开启通知」，点「**发送测试通知**」，确认手机 App 能收到。
5. 右上角出现状态灯：`同步 正常 / 待发送 / 异常`。

### 通知规则

- **每级只提醒一次**。一条产线从正常 → 预警 → 爆仓最多收到两条。
- **爆仓与耗尽两个方向始终都提醒**，没有单独的开关（曾经有过按方向开关的配置，实际很少有人用，已去掉）。
- 状态**恢复正常**（产线被清空、存量回落）后标记自动复位，下一轮跑到阈值时**会重新**提醒。
- 阈值：剩余时间 ≤ 设置面板里的「预警时间」（默认 30 分钟）时提醒一次，真正爆仓/耗尽时再提醒一次。
- **产销平衡（生产 = 消耗）不提醒**；刚添加、还没填数据的空行也不提醒。
- **每条物品单独推一条消息**（不合并）。标题形如 `⚠️ 即将爆仓：赤铜耐压罐（装满：液体A）`；正文只有一句：
  - 预警类 → `预计 14:32 爆仓（约 27 分钟后）`
  - 已爆仓 / 已耗尽 → `仓库已填满` / `物品已耗尽`
  - 正文不含存量、上限、净速率与日期（日期由 App 自身的通知时间体现）。
- 想重新接收已经提醒过的产线：点面板里的「**重置已提醒标记**」。
- 只走 App 通道：代码固定不传 `channel`，走 Server酱 默认通道。

### 时区

通知里的预计时间按面板所选的**固定 UTC 偏移**换算（默认 UTC+8），`/test` 的检查时间也同样处理。

- 列表覆盖 UTC+14 到 UTC-12 的全部整点，每档标注一个代表城市。
- 采用固定偏移，**不处理夏令时** —— 夏令时期间个别城市（如巴黎、纽约）会与实际当地钟点差一小时。
- 额度重置提示里的钟点也跟着这个设置走（Cloudflare 按 UTC 零点重置，UTC+8 即每天 8:00）。

### 同步方向：本地数据优先

同一个 Worker 只能有一个「通知源」，同步方向由面板上的「**本地数据优先**」决定（**默认勾选**）：

| 设置 | 行为 |
| --- | --- |
| **勾选**（默认） | **本地数据为准**：始终把本页面的产线上传上去。若 Worker 归别的页面所有，会自动接管并替换 Worker 上的数据。 |
| **取消勾选** | **Worker 数据为准**：从 Worker 拉取数据覆盖本页，**本页只读**（不再上传，避免把别的设备的数据改掉）。 |

不再有"要不要导入"的弹窗。想改主意直接切换这个勾选框，会立刻按新方向同步。

**换域名 / 换电脑时的正确姿势**：

- 想沿用旧数据 → **取消勾选**「本地数据优先」，刷新后数据会从 Worker 拉下来。
- 想用本页新数据覆盖旧的 → 保持勾选，同步一次即替换。

Worker 上属于旧页面、且不在本次快照里的行会被自动回收（`DELETE_AFTER_MISSES = 1`，一次同步就清掉）。

若想强制夺回（旧页面已经打不开），给 Worker 配一个 `CLAIM_TOKEN` 环境变量，然后：

```bash
curl -X POST "https://<你的 Worker>/claim?token=<CLAIM_TOKEN>" \
  -H "Content-Type: application/json" \
  -d "{\"clientId\":\"manual\",\"clientHost\":\"manual\",\"mode\":\"import\"}"
```

> `mode` 用 `import` 保留数据，用 `replace` 清掉旧数据。

### 同步时机与写入额度

页面**不做空闲轮询**，只在下面这些时刻同步：

- 进入页面 / 刷新时一次（无论有没有改动都发，好让状态灯有个确定结果、并发现 Worker 是否归别的页面所有）
- 确认修改退出编辑态、删除条目、改动通知设置
- 手动点「立即同步 / 测试」

**缓冲合并**：改动会先攒一小会儿（约 0.6–1.5 秒）再发；这期间又发生改动只是把计时器往后推。请求还没回来时再要同步，也只会在它结束后补发一次，不会并发打出多个请求。

同步时页面按内容比对，**没有改动就只发请求、不让 Worker 写任何键**。Cloudflare 免费版 KV 每天 1000 次写，正常使用基本碰不到上限。

状态灯文案只说明这次同步了什么：

| 文案 | 含义 |
| --- | --- |
| `已同步产线` | 本轮带上了产线数据的改动 |
| `已同步设置` | 只改了预警时间 / 时区等设置 |
| `已同步` | 例行同步，什么都没改 |

### 自检与排错

- `GET https://<你的 Worker>/version` — 只回 Worker 版本号，用来确认部署是否生效。
- `GET https://<你的 Worker>/test` — 触发一条测试推送，返回接口原始结果与所用地址模板。
- `GET https://<你的 Worker>/state` — 查看 Worker 掌握的行、等级与已提醒水位（需带 `X-Sync-Token` 头）。
- `GET https://<你的 Worker>/snapshot` — 导出 Worker 上的完整数据（页面导入用的就是这个）。
- `POST https://<你的 Worker>/claim` — 接管为通知源（见上一节）。
- `POST https://<你的 Worker>/reset-alerts` — 清空全部「已提醒」标记。
- 页面状态灯显示**推送异常**时，消息区会显示 Server酱 返回的原始错误（如 Key 失效、额度用尽）。
- 若显示 `KV 写入额度已用尽`：Cloudflare 免费版每天 1000 次写，用完后新数据推不进 Worker（页面会亮**红灯**），钟点按所选时区显示，届时自动恢复。
- 状态灯显示**版本不一致**时：说明改了 `worker.js` 但没在 Cloudflare 重新部署，重新粘贴并 Deploy 即可。
- 常见提示对照：
  - `未配置 SC_SENDKEY` — 变量没配，或配完没重新 Deploy。
  - `无法从 SendKey 解析 UID` — SendKey 不是 `sctp` 开头的格式，额外配一个 `SC_UID` 即可。
  - `未绑定 KV 命名空间 STATE` — KV 绑定的变量名写错了，必须一字不差是 `STATE`。
- **测试通知能收到、但从不自动预警** → 多半是 Cron Trigger 没加。

## 显示设置

页面底部的「**显示设置 · DISPLAY**」，用来换主题色与字体。**只保存在本机浏览器，不会同步到 Worker。**

| 项         | 说明                                                                 |
| ---------- | -------------------------------------------------------------------- |
| 主题色     | 点选色块即刻生效，默认「警戒黄」                                       |
| 中文字体   | 填字体族名（如 `Microsoft YaHei`），留空用默认                        |
| 英文字体   | 同上（如 `Consolas`），留空用默认                                     |
| 字体优先级 | 决定谁接管英文与数字：中文字体多自带拉丁字形，选错会盖住英文字体的效果 |

**主题色**共六种，都是对着暗色底挑的高饱和色（对比度均 > 7:1）：

| 名称   | 色值      | 名称   | 色值      |
| ------ | --------- | ------ | --------- |
| 警戒黄 | `#ffd21e` | 冰蓝   | `#6aa8ff` |
| 工业橙 | `#ff8a3c` | 紫晶   | `#b48cff` |
| 科技青 | `#4fd0e0` | 冷白   | `#dfe6ec` |

它替换的是界面里的高亮色（标题、按钮边框、进度条、选中态、预警计数等），**不改变状态语义**：爆仓方向仍是绿系、耗尽方向仍是红系，好与坏一眼可分。

- 输入后**回车或失焦**才生效。
- 含空格的字族名会自动加引号（否则 CSS 会把它拆成多个字体名而静默失效）。
- 两个字体都留空时使用默认栈，数字走等宽字体。

## 物品配置

图标放在 `items/` 目录，文件名与物品名一致（`.png`）。新增物品只需编辑 `items.js` 里的数组：

```js
window.ITEMS_CONFIG = ["源矿", "赤铜块" /* ... */];
```

页面刷新后下拉框自动同步；没有对应图标的物品会显示占位斜线。
