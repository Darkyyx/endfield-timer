# 终末地 · 产线倒计时

> Arknights: Endfield — Production Line Cap Countdown

填写产线的生产速度、消耗速度与当前库存，页面会自动算出产物**爆仓**或**耗尽**的剩余时间；需要的话还能接入手机推送，在即将爆仓或耗尽时收到提醒。

**[在线使用 →](https://darkyyx.github.io/endfield-timer/)**

---

## 快速上手

1. 点表格下方的「**＋ 添加产物**」新增一条产线。
2. 在新增的行里依次填写：
   - **产物名称** — 从下拉框里选（已内置常用物品与图标）。
   - **备注** — 可选，最多 32 字，用来区分同一种产物的不同产线（如「主账号」「小号」）。
   - **地区** — 武陵（上限 90,000）或四号谷地（上限 80,000）。
   - **生产/分**、**消耗/分** — 该产物每分钟的产出与消耗速度。
   - **当前库存** — 此刻仓库里的数量。
3. 填完点该行右侧的 **✓** 退出编辑态，倒计时立刻开始走。
4. 如需修改，点 **✎** 回到编辑态、改数字、再点 **✓** 即可重新计时。

数据会自动保存在浏览器里。

---

### 顶部统计

右上角常驻两个数字：

- **正常** — 产销平衡，或离阈值还远的产线数（不为 0 时显示绿色）。
- **预警** — 已进入预警窗口（即将爆仓 / 即将耗尽）以及已经爆仓 / 已经耗尽的产线数。一旦出现真正爆仓或耗尽的产线，这个数字会变红。

预警窗口的长度就是通知设置里的「预警时间」（默认 30 分钟）。

---

## 编辑与管理

- **修改** — 点行尾的 **✎** 进入编辑态，改完点 **✓** 保存。在编辑态里改数字时，库存会先按当时的时刻冻结，不会边改边涨。
- **删除** — 点行尾的 **✕**，该行立即移除。
- **排序** — 按住行首的 **⠿** 手柄上下拖动，可以调整产线顺序。
- **清空全部** — 点表格下方的「清空全部」，会二次确认，不可撤销。

---

## 显示设置

展开底部的「**显示设置 · DISPLAY**」：

- **主题色** — 六种（警戒黄 / 工业橙 / 科技青 / 冰蓝 / 紫晶 / 冷白）。只换界面高亮色，不改变上面的绿/红状态语义。
- **中文字体**、**英文字体** — 填字体族名（如 `Microsoft YaHei`、`Consolas`），**回车或失焦**后生效；留空则用默认。
- **字体优先级** — 决定谁接管英文与数字。中文字体通常自带拉丁字形，若发现英文字体设置"没反应"，把它切到「英文字体」优先即可。

这些设置**只保存在本机**，不会同步到其他设备。

## 手机通知（可选）

如果已经部署好自己的 Cloudflare Worker，就可以让页面关着也收到推送。

**开启步骤**

1. 展开「**通知设置 · NOTIFICATION**」。
2. 填入 **Worker 地址**（如 `https://xxx.workers.dev`，漏写 `https://` 会自动补全）与**同步令牌**。
3. 设置 **预警时间**（1–720 分钟，默认 30）——剩余时间进入这个窗口就提醒一次。
4. 选择 **时区**——通知里「预计几点爆仓」按这个时区换算，默认 UTC+8。页面上的目标时刻也用同一个时区，两边不会对不上。
5. 勾选「**开启通知**」，点「**发送测试通知**」确认手机能收到。
6. 右上角出现状态灯：`同步 正常` 表示数据已经送达 Worker。

**按钮说明**

| 按钮           | 作用                                       |
| -------------- | ------------------------------------------ |
| 发送测试通知   | 让 Worker 立刻推一条测试消息，验证整条链路 |
| 立即同步       | 不等自动同步，马上把当前数据推上去         |
| 重置已提醒标记 | 让所有已经提醒过的产线重新具备提醒资格     |

**「本地数据优先」勾选框**

| 设置             | 行为                                                                           |
| ---------------- | ------------------------------------------------------------------------------ |
| **勾选**（默认） | 以本页数据为准，始终上传。换了页面/域名时，会自动接管并替换 Worker 上的数据。  |
| **取消勾选**     | 以 Worker 数据为准，从 Worker 拉取后**本页只读**，不再上传，避免覆盖别的设备。 |

**会收到哪些提醒**

- 一条产线从正常 → 即将爆仓 → 已爆仓，最多两条消息；状态恢复后标记自动复位，下一轮还能再提醒。
- 产销平衡（生产 = 消耗）的产线不提醒；刚添加、还没填数据的空行也不提醒。
- 每条物品单独推一条，标题形如 `⚠️ 即将爆仓：赤铜耐压罐（装满：液体A）`，正文只有一句 `预计 14:32 爆仓（约 27 分钟后）`；已爆仓 / 已耗尽分别是「仓库已填满」「物品已耗尽」。

**同步时机**：进入页面/刷新时一次、确认修改退出编辑态、删除条目、改动通知设置、点「立即同步 / 测试」。页面**不做空闲轮询**，挂机时不会发任何请求；没有改动时也不会产生写入。

---

## 数据保存在哪

- 所有产线数据保存在本机浏览器的 `localStorage`，**换设备、换浏览器不会自动同步**。
- 只有开启通知后，数据才会经 Worker 中转；此时才涉及多设备/多页面之间的数据归属问题（见上一节的「本地数据优先」）。
- 清除浏览器数据会一并清掉产线与设置，请留意。

## 常见问题

**倒计时数字一直在涨/跌，但我没改过数据？**
这是正常的——页面按你最后填写的「库存 + 时间锚点 + 净速率」实时外推，不需要你每秒手动更新。想重新校准，点 **✎** 填入实际库存再点 **✓**。

**状态灯一直停在「待发送 / 等待首次同步」？**
检查 Worker 地址与同步令牌是否填对、Worker 是否已部署。地址写错时通常会显示「Worker 返回了非 JSON 响应」或 404 提示。

**状态灯显示「Worker 版本不一致」？**
页面与 Worker 的版本号对不上，说明 Worker 需要重新部署一次。

**显示「KV 写入额度已用尽」？**
免费版 KV 每天 1000 次写入，用完当天无法再写，页面会亮红灯，按所选时区显示的重置时刻自动恢复。

**测试通知能收到，但从不自动预警？**
多半是 Worker 的定时触发器没配（每 5 分钟一次），通知是由它巡检触发的，网页端只负责送数据。

**想重新接收已经提醒过的产线？**
点通知设置里的「重置已提醒标记」。
